# STAR BOUTIQUE – AutoCAD 2D Architectural Project

## Project Overview
This project is a conceptual architectural design of a modern single-storey commercial boutique, created using AutoCAD 2027.

The design focuses on retail space planning, customer circulation, clothing display arrangements and a simple modern shopfront.

## Drawings Included
- Ground Floor Plan
- Front Elevation
- Section B–A
- General Specifications
- Door and Glazing Schedule
- Drawing Legend

## Spaces Included
- Fitting Rooms
- Storage and Office
- Evening Wear and Couture Display
- Runway Display Area
- Accessories and Jewellery Section
- Cash Wrap and Service Counter
- Lounge Area
- New Collections Display
- Main Entrance

## Software Used
- AutoCAD 2027

## Drawing Details
- Building Type: Single-Storey Commercial Building
- Drawing Units: Feet and Inches
- Drawing Method: 2D Architectural Drafting

## Skills Practised
- 2D Architectural Drafting
- Floor Plan Preparation
- Front Elevation Drawing
- Section Drawing
- Layer Management
- Dimensioning and Annotation
- Retail Space Planning
- Door and Glazing Scheduling
